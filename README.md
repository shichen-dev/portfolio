# 🌐 时辰的作品集站点

基于 **HTML + CSS + 原生 JS** 构建的静态站点示例，  
使用 **Vite 多页面打包（MPA）**，并通过 **Cloudflare Pages / GitHub Pages** 部署。

🔗 **在线预览**  
https://shichen.pages.dev/

---

## ✨ 项目特点

- 🧩 **网格化布局**  
  使用 CSS Grid 构建信息密度较高的页面结构，适合作品展示与工具聚合。

- 🌗 **主题切换**  
  基于 CSS Variables 实现明暗主题切换，支持系统级自动适配。

- 🎞 **基础交互动效**  
  包含页面加载动画与常见 UI 状态反馈，提升浏览体验。

- 🧠 **多页面示例**
  - 内容展示类页面
  - 工具类页面
  - 交互示例页面

- ⚡ **Vite 多页面构建**
  - 解决多 HTML 场景下的构建与部署问题
  - 构建后仅输出 `dist/` 静态资源
  - 适合部署到各类静态托管平台

---

## 🛠 技术栈

- HTML / CSS / JavaScript
- Vite（多页面配置）
- CSS Variables
- 静态资源托管（Cloudflare Pages / GitHub Pages）

---

## 🚀 使用方式

### 安装依赖

```bash
npm install
```

### 本地开发

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

构建完成后，将 `dist/` 目录部署到：

- Cloudflare Pages
- GitHub Pages
- 任意静态服务器
